What it actually does

🔍 ETF look-through

Decodes your ETFs into their real holdings, so you see your true company exposure — not what the ticker list implies.

🎯 Hidden concentration

Finds names you hold both directly and inside funds, plus overlap between ETFs that quietly hold the same companies.

🌍 Region & sector tilt

Grouped into blocs — Europe, Emerging Asia, North America — because a regional event hits every name in it.

📰 Noise-filtered news

Only material items, scored by how much they touch your capital, deduplicated and capped so one busy stock can't flood the digest.

🧭 Plan drift

Your real allocation versus the targets you set, so you know where the next contribution is needed.

⏰ Automatic digests

Multiple schedules, each with its own frequency, depth and focus. On desktop they run automatically via Task Scheduler; on Android you tap a reminder to run. Delivered to console, Discord or email.

A look inside

On your phone (Android)

The whole app runs on Android too — the same TypeScript engine in a Tauri WebView, fully offline. Look-through, noise-filtered digests, history and delivery all work exactly like desktop. There's one download button for the APK up top; install it, then use Settings → Backup & transfer to bring your portfolio over from desktop.

Automation works differently on Android. On desktop, Windows Task Scheduler runs your digests fully automatically in the background — even with the app closed. Android forbids silent background execution, so instead a reminder notification fires at the scheduled time and you tap it to run the digest — one tap and it computes, delivers and saves. Missed reminders catch up the next time you open the app. Everything else is identical to desktop.

The portfolio total in the digest screenshot is blurred; the rest is a real run.

The rules it plays by

  • Numbers in code, prose in the AI. The model never does arithmetic on your portfolio.
  • No raw alerts. Every item explains why it matters to you.
  • Never optimize for action pressure. No buy/sell/hold, ever.
  • Honest data. Freshness and coverage are labelled; what can't be decoded is shown as such.
  • Local and private. Holdings stay on your machine. AI is optional and can run fully offline.

Get started

Install, add what you own (just a ticker is enough), and hit Run digest. Everything else is optional.

# or run from source (Rust + Node + MSVC build tools)
cd desktop-ts
npm install
npm run tauri dev        # desktop
npm run tauri build      # Windows installers

A pure-TypeScript engine in a Tauri 2 shell — same code on Windows & Android, no server, no Python. All data sources are free and public: Yahoo Finance for prices, Google News & Yahoo RSS for news, and iShares' daily holdings files for ETF look-through.
